# Counsellor Guide

This guide covers counsellor-specific screens and tasks.

## 1) Upcoming Sessions

Route: `/specialist/sessions`

Use this page to:

- View upcoming assigned sessions only.
- Review participant names and case context.
- Check submitted documents and flags.
- Open session briefing for each session.

## 2) Session Briefing

Route: `/specialist/sessions/:id`

Use this page before delivery to review:

- Participants
- Case notes
- Submitted documents
- Flags
- Previous session context

## 3) My Clients

Route: `/specialist/clients`

Use this page to:

- View only clients assigned to your cases.
- Open linked case/client context from your scope.

## 4) My Availability

Route: `/specialist/availability`

Use this page to:

- Mark available blocks.
- Mark out-of-office blocks.
- Apply preset morning/afternoon/evening batch blocks.
- Adjust day/week/month views for calendar planning.

Notes:

- Availability is used by ops during manual assignment mode.
- Out-of-office blocks are explicit and override availability.

## Permission Boundaries

- Counsellors do not see global ops dashboards.
- Counsellors do not manage workflow templates, operational settings, or other counsellors’ assignments.
